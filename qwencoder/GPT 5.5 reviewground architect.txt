## 1.3 What each module owns

## `nexus_kernel/`

This is the **only authoritative governance core**.

Owns:

* KAIJU auth decisions
* VAP/audit chain
* TokenGuard
* trust scoring
* canonical state changes
* approval records
* agent registry integrity

It must remain local-first because your governance threat model explicitly treats 7352 as the fail-closed governance plane and highlights API injection, registry corruption, context poisoning, KB prompt injection, and audit-log tampering as real threats. 

## `nexus_exec/`

This is the **execution substrate**, not the governance brain.

Owns:

* OpenShell providers and policy profiles
* Ollama Guard
* TWAVE execution wrapper
* sandbox dry-run tools

This matches the recommendation to use OpenShell as a governed execution provider behind Bridge/Governor, not as a replacement for Governor.  

## `nexus_bridge/`

This is the **interop/routing boundary**.

Owns:

* A2A adapters
* Cloudflare AI Gateway adapters
* Chimera routing
* ingress translation into internal proposals/tasks

This follows your own bridge stance: publish minimal public Agent Cards, treat remote agents as untrusted tools, and put Chimera in the routing layer with Cloudflare AI Gateway.  

## `nexus_memory/`

This is the **hybrid state layer**, not the sole truth layer.

Owns:

* local Vault storage
* L1 in-process cache
* Cloudflare KV cache
* D1 mirror
* R2 artifacts
* Vectorize retrieval
* sync logs and policy

This is the right placement because your Cloudflare notes already define D1/KV/Vectorize/R2 as hybrid memory/infrastructure services rather than truth authority. 

## `nexus_engine/`

This is the **task/workflow layer**.

Owns:

* DAG routing
* approvals pause/resume
* scoring event emission
* queue bridges
* task execution lifecycle

This aligns with your engine/task queue ideas and Cloudflare Queue inspiration for async dispatch. 

## `nexus_research/`

This keeps research/graph intelligence **adjacent but separate**.

Owns:

* Archivist / knowledge graph tooling
* DoppelGround adapters
* dataset merge logic
* research reports

That separation matters because Archivist and DoppelGround should feed structured evidence into Nexus, not merge into governance truth directly.

# 2. Cloud Memory Layer v0.1 Spec

## Status: proposed implementation draft

## 2.1 Scope

This layer exists to provide:

* fast distributed read-state
* dashboard/read decoupling
* artifact backup
* approved semantic retrieval
* graceful restart and recovery support

It does **not** provide:

* canonical truth authority
* policy mutation authority
* direct authorization
* unreviewed graph promotion
* raw prompt/session transcript authority

This matches the local-primary / cloud-mirror principle explicitly described in your Cloudflare integration notes. 

---

## 2.2 Authority model

## Canonical

Always local:

* project state
* decisions
* governance policy
* trust truth
* VAP chain
* KAIJU rules
* approvals

## Derived / mirrored

May be cloud-served:

* cached governance decisions
* trust score snapshots
* budget snapshots
* dashboard summaries
* semantic retrieval indexes
* immutable artifacts

## Rule

Every cloud-served item must carry:

```json
{
  "source": "local_7352",
  "authoritative": false,
  "vap_hash": "0x...",
  "computed_at": "ISO-8601",
  "expires_at": "ISO-8601"
}
```

---

## 2.3 Services and responsibilities

## A. KV Cache

**Purpose:** edge cache for hot reads

Stores:

* governance decision snapshots
* trust score snapshots
* token/model budget state
* route selection summaries
* dashboard provider summaries

**Priority:** P0
This matches the P0 designation in your Cloudflare notes. 

### Example keys

```text
gov:decision:{agent_id}:{action}:{resource_hash}
trust:snapshot:{agent_id}:{lane}
budget:model:{model_id}
budget:agent:{agent_id}
route:selection:{agent_id}:{intent_hash}
dashboard:summary
dashboard:provider:{provider_id}
```

### TTL policy

| Key type            |      TTL |
| ------------------- | -------: |
| governance decision |  60–300s |
| route selection     |  30–120s |
| trust snapshot      | 300–900s |
| model/agent budget  |  60–300s |
| provider summary    |   15–60s |
| dashboard summary   |  60–600s |

---

## B. D1 Mirror

**Purpose:** read-only mirror for dashboards, reporting, and recovery-friendly queries

Mirrors:

* trust snapshots
* scoring events
* governance event summaries
* route summaries
* agent status summaries

**Priority:** P1
Also matches your Cloudflare priority matrix. 

### Mirror rules

* local remains primary
* D1 never writes back into canonical state directly
* mirror sync must be idempotent
* every mirror write must be logged locally first

---

## C. R2 Artifact Store

**Purpose:** immutable object storage for audit and heavy outputs

Stores:

* VAP bundles
* scoring event exports
* TWAVE run artifacts
* evaluation outputs
* approved Archivist export bundles
* dataset chunk snapshots / backup

**Priority:** P2
That also matches your current service ranking. 

### Object naming suggestion

```text
r2://nexus-artifacts/{year}/{month}/{artifact_type}/{artifact_id}.json
r2://nexus-artifacts/{year}/{month}/{artifact_type}/{artifact_id}.zip
```

---

## D. Vectorize / semantic index

**Purpose:** semantic retrieval over approved knowledge only

Indexes:

* approved Archivist nodes
* compiled wiki notes
* governance KB
* ops KB
* research KB

This matches both:

* your Cloudflare Vectorize direction
* your DO knowledge-base design mindset of separated KBs with different chunking/rerank strategies.  

### Important constraint

Only index nodes that already passed:

* truth-layer requirements
* integrity gate
* canonical linkage rules

Archivist already moved toward enforced `truth_layer`, `canonical_ref`, confidence, and integrity gating, so this is the right prerequisite.

### Example usage

```python
decision = kv_cache.get(f"gov:decision:{agent_id}:{action}:{resource_hash}")
if decision and not is_expired(decision):
    return decision["value"]

local = governor.evaluate(...)
vap_hash = vap.log(local)
kv_cache.set(
    key=f"gov:decision:{agent_id}:{action}:{resource_hash}",
    payload={
        "source": "local_7352",
        "authoritative": False,
        "vap_hash": vap_hash,
        "computed_at": now_iso(),
        "expires_at": ttl_iso(120),
        "value": local,
    },
    ttl_seconds=120,
)
return local
```
