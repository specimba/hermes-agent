### 2.6 TokenGuard Integration

CODEX patched OPUSman v6.3 to inject the pre-flight check inside the `delegate()` method before any API requests. It calculates estimated cost dynamically (compressed prompt tokens + max output tokens for the specific domain). If `token_guard.can_spend()` returns false, the agent short-circuits and returns a clean 429 Deny result.

### 2.7 Trust Scoring v2.1 Formula

This is original math from SPECI's ideas, not borrowed:

```
Qeff = max(0, (Q - qmin)/(1 - qmin)) * (1 - exp(-n/n0))
P = α·U + γ·D+ - β·R - η·D-
raw_score = tanh(κ · Qeff^δ · P)
```

Seven hard invariants:
- INV1: blocked/unassigned → score=None, finding=NONE
- INV2: hard_fail OR R>Rcrit → score=-1.0, finding=ESCALATED
- INV3: score ∈ [-1.0, 1.0] (asserted, not clamped)
- INV4: finding_state tracked
- INV5: R>Rcrit → held (COMPLIANCE/AUDIT) or escalated (others)
- INV6: Qeff bounded by q_gated and exp decay
- INV7: ε-gate: |raw|<ε → score=0.0

Post-processing: logistic scaling (0–1 via sigmoid) followed by temporal decay (rate=0.05).

Lane parameters vary by domain — research has Rcrit=0.8, qmin=0.3, n0=5; audit_sec has Rcrit=0.4, qmin=0.7, n0=2; compliance has Rcrit=0.2, qmin=0.8, n0=1.

### 2.15 Key Technical Insights

1. **Windows asyncio/Winsock failure** is an environment-class problem, not agent-specific. If one agent hits it, others likely will too. CODEX recommended: *"If Windows keeps failing, move those wrappers to WSL2 or a container, while Nexus core remains local Windows Python."*

2. **Token audit bloat** (~24K/cycle) needs compaction: rolling compact state file, heartbeat packets under 300 tokens, no raw log pastes after first ingestion, compaction every 3–5 turns.

3. **"Vault" terminology** caused AI to hallucinate DeFi financial language. System prompt fixed in `/api/chat/route.ts` and `/api/claude/route.ts`.

4. **Tool schema overhead**: 4,000–7,000 tokens per call even without using tools. Selective single-tool usage yields 44.6% savings.

5. **Radix ScrollArea bug**: `min-h-0` is the critical fix for flex children not shrinking below content size.

6. **Kiro file watcher**: 12 processes consuming 2.5GB RAM and 350+ CPU seconds. Phantom file changes with no actual modifications. Issue #4826.

7. **Copy-paste bottleneck**: Human can only communicate 1-by-1 with agents. Solution: A2A for agent-to-agent, MCP for tools, durable workflow layer for retries.

8. **Test count discrepancy**: Multiple development branches with inconsistent merges. Solution: `TEST_MANIFEST.json` as single source of truth.

## 9. Critical Lessons (Consolidated Across All Logs)

1. **Claims ≠ Verification** — agents said tasks were done, files stayed in `pending/`. Always verify with test output, diff, or folder movement.

2. **Import ≠ Integration** — OPUSman imported VaultManager but called methods that didn't exist. `try/except` silently swallowed the errors. Deep verification found the gap.

3. **Grok needs CODEX audit** — Grok produces fast and comprehensive, but CODEX must verify before acceptance. This is now the operational standard.

4. **635+ was never real** — actual count was 622 (Zo) or 631 (Codex with task contract tests). The number was carried forward from unverified reports.

5. **Mem0 was already replaced** — Vault/5-track is canonical. SuperLocalMemory (S-Layer) for OPUSman. OPUSman code still referenced Mem0Adapter — caught and fixed.

6. **Port drift is real** — one canonical port map must be enforced. 7352/7353/7354 confusion persisted across multiple files and reports.

7. **SPECI's correction pattern works** — honest feedback → immediate correction → grounded execution. This is the governance model in action.

8. **A2A protocol is not ready** — 8+ failed attempts. Build custom or wait for maturity. META team is leaning toward building custom.

9. **Tool schema overhead is massive** — 4,000–7,000 tokens per call even without using tools. Selective single-tool usage is essential.

10. **"Vault" causes hallucinations** — AI sees DeFi when it reads "Vault". System prompt fix applied.
