2. The Boot Sequence (nexusctl up)
A release-ready OS must have a deterministic, safe boot sequence. When the user types nexusctl up, the system initializes in strict dependency order:
Phase 1: Substrate Lockdown (Pre-flight)
Executes ollama_guard.ps1.
Applies Windows Filtering Platform (WFP) rules: Blocks all unauthorized PIDs (e.g., rogue IDE extensions) from accessing Port 11434.
Verifies NVIDIA NVML health and GPU memory state.
Phase 2: Memory & State Hydration
Pings Zilliz nexus-serverless (Hot Cache) and nexus-os-town (Cold Storage).
Syncs local SQLite Vault state with Cloudflare D1 (Edge Replica).
Loads TokenGuard budgets from Cloudflare KV.
Phase 3: Kernel Ignition (Port 7352)
Starts the FastAPI Governance Plane.
Loads KAIJU policies and initializes the VAP cryptographic chain.
Phase 4: Bridge & Execution Readiness
Initializes Chimera Router (verifies connection to 50+ free APIs via CF Gateway).
Pre-warms NVIDIA OpenShell sandbox templates.
Publishes the A2A Agent Card (Public Discovery).
3. The Execution Flow (The Lifecycle of an Agent Action)
To guarantee 0% violation rates (matching the MS AGT baseline), every action follows this exact pipeline:
Intent Generation: Agent A (e.g., OPUSman) wants to execute a Python script.
Proposal Submission: Agent A cannot execute directly. It submits a Proposal to Port 7352.
KAIJU Gate (Kernel): The Governor checks the agent's Trust Score (Zilliz) and Token Budget (CF KV).
Chimera Routing (Bridge): Chimera determines this is a low-VRAM task and routes it to the ECO pool (Local TWAVE/Bonsai 1-bit).
OpenShell Jailing (Exec): The task is wrapped in an OpenShell code_exec.yaml policy (No network access, read-only filesystem except /tmp).
Execution & Audit: The code runs. The result is hashed by VAP and stored in the EVENT track.
Archivist Synthesis: If the result is valuable, Archivist v5.0 promotes it from EXTRACTED to INFERRED knowledge.
